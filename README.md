# 给 Sunay 的作品集

这是Cloud为Sunay做的个人作品集网站。

我希望它不只是一个摆放作品的网页，也能成为一扇小小的窗口：让第一次认识你的人，看见你的审美、想法和认真做过的每一件事。

网站已经准备好了，你不需要了解代码，也不用操心它是怎么运行的。以后想加入新作品、调整介绍或更换图片，直接使用网站里的编辑页面就可以。

## 怎么修改网站

打开 [作品编辑页面](https://sunay04.vercel.app/edits)，登录后就能看到现在的网站内容。

你可以在这里：

- 新建、修改或删除作品；
- 调整作品的展示顺序；
- 修改标题、介绍和其他文字；
- 添加图片、视频、音频或 PDF；
- 调整正文内容和排版；
- 修改音乐列表。

编辑时，内容会先保存在当前浏览器里，所以可以慢慢整理，不必一次完成。不过这些修改还只是草稿，只有主动发布后，访客才能看到。

## 发布之前

内容整理好后，可以先点击「预览」，检查作品页面实际展示出来的效果。

确认没有问题，再依次点击「检查并发布」和「确认发布全部修改」。发布完成需要稍等一会儿，页面提示成功后，新内容就会上线了。

为了避免出错，发布前可以简单检查一下：

- 标题和介绍有没有错别字；
- 图片顺序是否正确；
- 视频、音频和 PDF 能否正常打开；
- 手机和电脑上的阅读效果是否舒服；
- 有没有还没写完、暂时不想公开的内容。

## 如果看到内容冲突提示

这通常表示你打开编辑页面以后，线上内容又被其他窗口修改过。网站会阻止旧内容直接覆盖新内容，所以不用担心。

先点击「备份草稿」，把自己的内容保存下来；然后点击「载入线上版本」，再参考备份把需要的修改补回去即可。

尽量不要同时在多个窗口里编辑，也不要在发布过程中重复点击发布按钮。

## AI 帮你完善作品

编辑作品时，可以点击「优化简介」「改善这段」或「检查作品完整度」。补充自己的真实职责与创作过程，助手会给出可逐条采纳的文字建议和待补问题。采纳只更新草稿，仍需预览并主动发布。
