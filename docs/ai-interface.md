# AI 助手界面约定

## Overview

这是现有作品编辑台的局部扩展，采用 Operate 模式：浅灰、紧凑、以编辑任务为中心。入口位于作品完整度检查、简介字段下方与正文文本块操作区；面板只在作品编辑模式中显示。

本文仅记录 `src/editor/AiAssistant.tsx`、`src/editor/ai.css` 与 `EditorPage.tsx` 的 AI 集成。全站视觉系统、公开作品页和其他编辑页面不在范围内；不修改根目录 DESIGN.md 或设计 sidecar。服务配置和接口限制见 [AI 助手说明](ai-assistant.md)。

## Colors

继承编辑台浅灰背景 `#f2f3f5` 和分隔线 `--editor-line`（`rgba(19,22,26,.1)`）。助手表面为 `#fbfcfd`，正文为 `#20252c`；选中模式与生成按钮使用深蓝灰 `#263b50` 搭配白字。错误为 `#a02c25`，采纳状态为 `#315d48`，均配有明确文字。输入框为白底，光标及已有键盘焦点强调色为 `#235eb0`。

## Typography

继承编辑台系统字体栈：`-apple-system, BlinkMacSystemFont, "SF Pro Text", "PingFang SC", sans-serif`。正文 `.82rem`、行高 `1.7`；主标题 `1.1rem`，结果分节标题 `.9rem`，建议标题 `.85rem`，标题字重 `650`。辅助文字约 `.7–.76rem`。原文、建议和问题允许长文本换行；结果保留文本换行。

## Layout

| 视口宽度 | 面板展开后的布局 |
| --- | --- |
| 大于 1100px | 作品列表 `12rem`、弹性画布、右侧助手 `minmax(20rem,24rem)` |
| 901–1100px | 作品列表 `10rem`、弹性画布、助手 `21rem` |
| 641–900px | 保留 `10rem` 作品列表；助手占第二列并替代画布 |
| 不大于 640px | 继承编辑台纵向布局和横向作品列表；助手占满剩余宽度与空间，替代画布，移除左边框 |

面板标题区不随内容滚动，正文区独立纵向滚动。常规正文内边距 `1.25rem`；不大于 1100px 时为 `1rem`，手机正文底部增加到 `2rem`。模式按钮允许换行；常规按钮最小高度 `2.5rem`，手机上模式与次要按钮为 `2.75rem`。顶部原有导航、预览与发布入口继续可用，关闭助手恢复画布。

## Elevation & Depth

助手通过淡色表面与细分隔线建立层次，不增加浮层阴影。窄屏替代画布时使用 `z-index:9`，并非遮盖整个编辑台的模态框。

## Shapes

继承编辑台小圆角按钮和字段。模式按钮使用 `5px` 圆角；建议条目依靠留白和底部分隔线组织，不增加嵌套卡片。

## Components

- **任务与输入：** 三种模式为优化简介、改善段落、检查完整度。段落模式提供目标选择；没有文本块时提示先添加文本块。补充说明选填，最多 4000 字。生成前明确说明发送给 DeepSeek 的文字范围和草稿用途。
- **服务状态：** 检查中禁用生成；未配置或连接错误时显示具体提示及「重新检查」。段落目标未选定时也禁用生成。
- **生成状态：** 显示加载图标和「正在生成建议…」，禁用模式、输入、采纳与撤销，提供取消。取消保留已有建议与草稿；失败显示错误并允许重试。
- **结果：** 按概述、逐条原文／建议文案／修改理由、待补问题排列。问题可在上方补充说明中回答后重新生成。采纳按钮只写入草稿；原文已变化时禁用采纳并提示重新生成。
- **采纳与撤销：** 已采纳条目显示确认文字，历史按最近采纳优先排列并支持逐条撤销。目标文字后来发生变化时禁用撤销，避免覆盖后续编辑。关闭面板或切换预览保留当前作品的建议；切换作品或刷新清空临时建议、补充说明与撤销记录，已采纳草稿沿用原有保存机制。
- **焦点与辅助技术：** 打开时将焦点移到面板标题；关闭时尝试返回仍存在的原入口。标题使用程序焦点并隐藏自身轮廓，交互按钮与选择框继承可见焦点环。面板有可访问名称，关闭按钮有文字标签，模式以 `aria-pressed` 表示选中；状态使用 `role="status"`，错误使用 `role="alert"`。焦点位于面板内时 Escape 可关闭；不限制焦点在面板内循环。

## Do's and Don'ts

- 保留字段旁的上下文入口、原文与建议的可比较性，以及明确的关闭路径。
- 逐条采纳后继续原有「预览 → 检查并发布」流程；AI 不自动发布。
- 扩展限定于文字建议，不改变作品布局、不自动增加内容块或生成图片。
- 本轮独立界面审阅在 1440×1000 和 390×844 下结论为 ship，无实质 UI 问题；此结论不代表真实供应商接口已联调。
